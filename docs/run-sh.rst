run.sh file
===========

This file is here to show the git update made by my script. It works as follow :

.. code-block:: bash

  ./run.sh # Solve the current puzzle
  ./run.sh [--git-update|-gu] # Solve the current puzzle and send the filtered dictionary to the configured git repository


By default, this script use the default configuration file, save statistics and update the dictionary with invalid words found during solving
